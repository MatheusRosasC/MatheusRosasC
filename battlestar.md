# Battlestar

**Personal project · In progress · Local development**

Battlestar is a persistent space strategy game played in the browser. I use the project to connect software development, product decisions, quality and application security.

## Current local scope

- Persistent accounts and game state.
- Empire progression, resource management, research and ship construction.
- Exploration, colonization, fleet operations and combat.
- Alliances, communication and market interactions between accounts in the same installation.
- Automated tests, documented behavior and backup/recovery routines.

## Technology

JavaScript, HTML, CSS, Node.js 24+ and SQLite.

## Connection to my Cybersecurity and DevSecOps path

The project gives me practical context for studying authentication, authorization, server-side validation, data integrity, testing and recovery. Security is an ongoing engineering concern throughout development.

## Status and boundaries

The game remains in local development. It is not presented as a public production service or a professionally audited security product. Public hosting, operational readiness and real external integrations require further work.

This page is a public project overview. The development repository is private; account records, credentials and local operational data are not part of this portfolio.
