# TheFinance

**Personal project · In progress · Local development**

TheFinance is a personal finance application designed to run locally, with a Portuguese interface and values in Brazilian reais.

## Current local scope

- Income, expenses, transfers, search and filters.
- Financial accounts, credit cards, installments and invoices.
- Budgets, savings goals, monthly reports and cash-flow views.
- CSV import with preview, export, backup and restore.
- Separate records for each authenticated user.
- An isolated demonstration mode with fictional data.

## Technology

JavaScript, HTML, CSS, Node.js 24+ and SQLite. A rule-based local assistant helps with supported commands; it is not a generative AI service.

## Connection to my Cybersecurity and DevSecOps path

The application provides practical context for studying authentication, authorization, user data isolation, session handling, input validation, transactional integrity and recovery. These concerns connect software quality with protection of financial information.

## Status and boundaries

The application runs locally and remains under development. It does not connect to banks, execute bank transfers or provide Open Finance integration. Recording a payment updates the local financial records only.

This page is a public project overview. Personal financial records, credentials and backups are not included.
